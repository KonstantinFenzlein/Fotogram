# Fotogram

Persönliches Foto-Album im Browser: Bilder in einer Galerie ansehen und im Dialog groß durchblättern.

## Funktionen

- Galerie-Übersicht aller Bilder
- Großansicht im Dialog mit Vor- und Zurück-Navigation
- Automatische Diashow (Start/Stopp)

## Technologien

HTML5 · CSS3 · JavaScript (ohne Framework)

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Fotogram.git`
2. `index.html` im Browser öffnen – keine Installation nötig.
